# 运行手册

运行手册记录可重复执行的操作与故障恢复，不承担产品规则或设计理由。

## 当前入口

| 操作 | 权威入口 |
|---|---|
| 安装、启动、开发、打包、本地模型安装 | [仓库根 README](../../README.md) |
| 新增或修改语音指令 | [语音指令生成指南](../voice-command-agent-guide.md) |
| 查询逐字稿、配置、LLM 和会议白板 | `scripts/rtc.mjs --help`；命令概览见根 README |
| 常见体验故障与已知症状 | [体验问题合集](../product-rules/ux-issue-log.md) |

新增手册应包含：适用场景、前置条件、可复制步骤、成功信号、失败时的停止条件、回滚或恢复方式、最后验证日期。涉及真实用户数据、权限或进程终止的操作必须明确风险，不能把危险命令包装成“常规修复”。
