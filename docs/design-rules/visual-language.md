# 视觉正本：纸和墨

> **状态：已并入 [DESIGN.md](DESIGN.md)（2026-09-30），不再作为正本。** 本文件仅作历史参考；
> 现行视觉正本是 DESIGN.md（唯一正本）。

这份文件描述 RTC 主界面的视觉语言，以及三处**例外表面**（菜单栏、会议白板、通知音效之外的系统反馈）。

**数值的唯一来源是代码**，本文解释它们、不替代它们：

| 来源 | 管什么 |
|---|---|
| `src/css/style.css` 的 `:root` | 颜色、圆角、字体族 |
| `src/css/style.css` 正文 | 字号、间距、动效时长、层级 |
| `src/js/tray.js` | 菜单栏颜色与字形 |
| `src-tauri/src/lib.rs` 的 `TRAY_SLOT_WIDTH` | 菜单栏那一格的宽度 |

## 1. 底色、文字与强调色

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#f3ede2` | 页面底色（米黄纸） |
| `--paper-2` | `#ece4d4` | 次底：悬停底、浅色块、未选中标签底 |
| `--ink` | `#1a1611` | 正文与图标主色（墨） |
| `--ink-soft` | `#524b3e` | 次级文字：图标默认态、状态文字 |
| `--ink-faint` | `#8f8572` | 最淡一档：空态、提示、未激活刻度 |
| `--rule` | `#d4cbb6` | 分隔线、描边 |
| `--seal` | `#bf3a1e` | **唯一强调色**（印章红） |
| `--seal-deep` | `#8f2a14` | 异常态：服务未连接、麦克风不可用 |

印章红只出现在三处：**录音中的圆点、输入光标、悬停与键盘焦点提示**。顶栏那一排图标自己卡例外——
悬停给 `--paper-2` 底色、**不占红色填充**；键盘聚焦仍是全站统一的 `2px solid var(--seal)` 描边
（2026-09-20 核对：`style.css` 里 23 处 `:focus-visible` 全部如此，与 `ui-interaction-spec.md` 第 1 节主句一致）。

颜色**只在 `:root` 定义一次**，组件里不许写死色值。但现实里还有两个未被规则承认的“第二强调色”：
更新提示条的黄色系与测试通过的绿色（见第 5 节）。它们不是灵感，是**尚未登记的偏差**——
要么收进规则，要么改掉，见 [治理合同](governance.md) 的 D-5 / D-6。

## 2. 排版

- **字体族**：等宽（`--font` / `--mono`），到处统一——它同时是「像纸不像后台」的一部分。
- **已确认的层级**（正文里长期稳定、可以作为依据的）：
  - 逐字稿正文 `15px / 1.7`
  - 页面与区块标题 `15–16px`
  - 分组与时间分隔条 `11–12px`
  - 时间戳、统计数字 `10–11px`，并一律用 `font-variant-numeric: tabular-nums`
- **尚未收敛**：`font-size` 在 `style.css` 里还散着 8 / 10 / 11 / 12 / 13 / 14 / 15 / 16 / 18 / 20 / 22 / 30px 多档，
  其中 12px 与 11px 出现频次最高。规划字号阶梯属于**产品判断**，本文不新增；
  新增字号时优先复用上面已确认的档位。

## 3. 形状、图标与动效

- **圆角**：`--radius: 4px` 与 `--radius-sm: 3px` 是正本；胶囊类元素用 `999px`（`--engineBadge`、设置页开关）。
  现存 2 / 6 / 8 / 10px 是历史遗留，改到附近代码时优先归到 token，不为此单独发起重构。
- **图标**：一律内联 SVG，**项目内 0 emoji**。统一 `24×24 viewBox`、`stroke-width: 2`、`round` 端点
  （顶栏那一排渲染为 17×17px）。纯图标按钮必须同时有 `title` 与 `aria-label`。
- **提示**：悬停解释统一走 `data-tip`；用了 `data-tip` 的元素**不要**再设 `title`，否则系统提示会叠着弹。
- **动效**：都是短过渡，`0.12s–0.22s` 为主，缓动 `cubic-bezier(.16,1,.3,1)` 用于位移与底色，
  `width .3s` 只用于真正的尺寸变化（进度、展开）。
- **禁止**：引进第二种强调色、大圆角卡片、渐变按钮、阴影堆叠、emoji 图标。

### 动效不能撒谎（一条硬约束）

**每一帧由 JS 写入的属性，不要再挂 CSS `transition`。** 电平条 `#levelMeterBar` 上禁止
`transition: width`：JS 每帧写宽度时，过渡会让每次写入从「上一次的中间值」重新起步，
显示值恒低于真实电平且追不上声音。快起慢落由 `src/js/meter.js` 的包络负责，CSS 不插第二只手。
同理，电平条的**染色必须跟着画出来的电平走**（`meter.tone` + `TONE_HOLD_MS = 220`），
否则会出现「红色实时条在收回途中变灰」——那是一条在视觉上说谎的动效。

## 4. 可读性

- 正文与背景对比度 **≥ 4.5:1**，大号字 **≥ 3:1**。这不是外部标准：
  项目自己曾把「色带压过刻度把对比度从 5.19 拉到 3.07」当 bug 修（见 `ux-issue-log` UX-3）。
- 判定方式是自动的：`npm run check:ux` 用真实浏览器量对比度、可点区域（< 16px 判过小）、
  被裁/被盖/够不着的内容。**新增可见元素时它是最低门槛。**

## 5. 例外表面与待裁决项

### 菜单栏（macOS 层，不受 `:root` 约束）

| 项 | 值 | 说明 |
|---|---|---|
| 说话中底色 | `#FF9230` | 胶囊形状，圆角取高度一半，画在系统按钮图层上 |
| 异常态 | `#D93025` | 麦克风/服务异常 |

`src-tauri/src/lib.rs` 的注释。**白色柱形压在 `#FF9230` 上只有约 2:1 对比度**——
这是已知的、被接受的取舍（投屏级可读性未做过验收）。

### 会议白板（独立外观，待裁决）

白板是独立 HTML 入口，只加载自己的样式，**不加载主界面那份 `:root`**：
底色 `#faf9f7`（近纯白）、文字为中性灰（`#999 / #666 / #555 / #2c2c2c`），
还引入了第二个强调色 `#c9a227`（整理失败态）。实测 `meeting-board/src/style.css` 里
写死颜色 89 处、使用共享 token 0 处。

这是 `ux-issue-log` 的 **UX-4，状态「待定」**：白板是投给一屋子人看的那块板，
故意做成纯白高对比是站得住的（投影仪上纸色发灰）；若不是故意的，白板应接进共享调色板。
**在裁决之前，本文不把白板算作违规，也不把它算作合规**——改动白板前先读 UX-3 / UX-4，
并按 [治理合同](governance.md) 登记。
